# 🥔 Brotato Mini

Арена-выживалка в стиле [Brotato](https://store.steampowered.com/app/1942280/Brotato/). Выживи 20 волн нарастающей орды — картошка сама стреляет, тебе нужно только двигаться.

---

## Геймплей

Каждая волна — таймер. Враги спавнятся и идут на тебя. Ты двигаешься, игрок стреляет автоматически по ближайшему врагу. Убиваешь — получаешь XP и материалы. Умираешь — Game Over.

После каждой волны открывается **магазин**: тратишь материалы на улучшения, жмёшь «Следующая волна».

**20 волн** — победа. На всё про всё.

---

## Управление

| Клавиши | Действие |
|---|---|
| `WASD` / Стрелки | Движение |
| — | Стрельба автоматическая |

---

## Враги

| | Тип | Особенность |
|---|---|---|
| 🟢 | Зелёный | Быстрый, хлипкий |
| 🟣 | Фиолетовый | Обычный |
| ⚫ | Серый | Танк, медленный |
| 🔴 | Красный элитный | Появляется с 5-й волны, много HP и урона |

Перед появлением каждого врага — мигающий красный круг на месте спавна.

---

## Прокачка

- **XP** → автолевелап: каждый уровень +5 к максимальному HP и +10 HP восстановление
- **💜 Материалы** → валюта магазина, дропают из врагов
- **Волны** становятся длиннее (20 → 60 сек) и злее с каждым кругом

---

## Параметры игрока

HP · Скорость · Урон · Скорострельность · Пробитие · Лайфстил — всё прокачивается через магазин.
