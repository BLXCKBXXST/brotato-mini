# 🥔 Brotato Mini

Арена-выживалка в стиле [Brotato](https://store.steampowered.com/app/1942280/Brotato/). Выживи 20 волн нарастающей орды — картошка сама стреляет, тебе нужно только двигаться.

## Геймплей

Каждая волна — таймер. Враги спавнятся и идут на тебя. Ты двигаешься, игрок стреляет автоматически по ближайшему врагу. Убиваешь — получаешь XP и материалы 💜. Умираешь — Game Over.

После каждой волны открывается **магазин**: тратишь материалы на улучшения, жмёшь «Следующая волна». 20 волн — победа.

## Управление

| Клавиши | Действие |
|---|---|
| `WASD` / Стрелки | Движение |
| — | Стрельба автоматическая |
